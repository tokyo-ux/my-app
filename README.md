# my-app

ブロック崩しMVP

概要

このリポジトリはシンプルなブラウザ向けブロック崩しゲームです。index.html と game.js を使って動作します。

遊び方

- 目的: すべてのブロックを壊す。
- 操作:
  - 左右移動: ← / → キー、または A / D
  - 発射/開始: スペースキー（ゲームが停止中のとき）
- ルール: ボールを落とさないようにパドルで跳ね返してブロックに当てます。ライフやスコアは画面上に表示されます（実装に依存）。

ローカルでの実行方法

1. リポジトリをクローンまたはファイルを取得する。
2. ブラウザで直接開く: index.html をダブルクリックして開くだけでも動作します。
3. 簡易サーバーで起動する (推奨、CORS を避けるため):

   - Python 3: `python3 -m http.server 8000` を実行し、http://localhost:8000 を開く

開発

- 主なファイル:
  - index.html — ゲームの起点（HTML / Canvas）
  - game.js — ゲームロジック
- 変更後はブラウザをリロードして動作を確認してください。

デプロイ (GitHub Pages)

GitHub Pages: https://tokyo-ux.github.io/my-app/

サイトのコンテンツは index.html をルートに置いて公開しています。リポジトリの Settings → Pages で公開ブランチ（例: main）とフォルダ（root）を選択してください。
